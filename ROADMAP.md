## 🎯 Назначение документа

Этот файл описывает **последовательность разработки** всех материалов курса «Мульти-агентная разработка приложений». Он фиксирует:

1. Понимать, **что создавать в первую очередь**
2. Видеть **зависимости между артефактами**
3. Соблюдать **правильный порядок разработки**
4. Контролировать **готовность каждого этапа**

> ⚠️ **Источник истины по темам и неделям — `syllabus.md`.** Этот ROADMAP описывает только *порядок производства материалов*. Если темы цикла в ROADMAP и syllabus расходятся — прав syllabus, ROADMAP нужно исправить.

## 🎯 Приоритеты разработки

### P0 (Критично — делать в первую очередь)

1. Сценарии для преподавателя (`workshops-teacher/*`) — без них невозможно провести занятие

3. Чек-листы и рубрики (`assessment.md`, `rubrics/*`) — необходимы для оценивания

### P1 (Важно — делать во вторую очередь)

1. Материалы для студентов (`workshops/*.md`) — могут быть адаптированы из сценариев

3. Troubleshooting guides — помощь при типичных проблемах

1. Презентации (`workshops-teacher/*/…-slides.md`) — визуальная поддержка
2. Дополнительные примеры кода
3. Расширенные шаблоны ADR
