# Учебный бэкенд

Минимальное FastAPI-приложение для практики 1, если у команды ещё нет своего бэкенда из курса «Конфигурирование»: `GET /`, `GET /health`, `POST /notes`, `DELETE /notes/{note_id}`, данные в памяти, без базы.
Скопируйте каталог рядом с репозиторием помощника и укажите его в `.env` помощника: `AI_REPO_ROOT=../sample-backend`.
Когда появится свой бэкенд, поменяйте эту строку на `AI_REPO_ROOT=../<проект>` — больше ничего менять не нужно.
Запускать приложение не обязательно: помощник только читает `main.py`. Запуск для любопытных: `pip install fastapi uvicorn`, затем `uvicorn main:app`.
