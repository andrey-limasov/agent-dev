# Заметки

Учебный бэкенд на FastAPI: создаёт и удаляет текстовые заметки.
Данные живут в памяти процесса, базы данных нет. Версия — 0.1.0.

## Быстрый старт

Нужен Python 3.11–3.13.

1. Создайте виртуальное окружение: `python -m venv .venv`.
2. Активируйте его и установите зависимости: `pip install fastapi uvicorn`.
3. Запустите сервер: `uvicorn main:app --reload`.
4. Откройте `http://127.0.0.1:8000/docs` — интерактивная документация.

Проверка: `curl http://127.0.0.1:8000/health` возвращает `{"status": "healthy"}`.

Остановить сервер — `Ctrl+C` в том же терминале.

## Эндпоинты

| Метод | Путь | Что делает | Успех | Ошибки |
|---|---|---|---|---|
| GET | `/` | Приветствие | 200, `{"message": "Sample Backend"}` | — |
| GET | `/health` | Проверка, что сервис жив | 200, `{"status": "healthy"}` | — |
| POST | `/notes` | Создаёт заметку из `title` и `text` | 201, заметка с полем `id` | 422, если нет `title` |
| DELETE | `/notes/{note_id}` | Удаляет заметку | 204, пустой ответ | 404, `{"detail": "Note not found"}` |

Поле `text` необязательное, по умолчанию — пустая строка.

## Ограничения

- Заметки пропадают при каждом перезапуске сервера.
- Прочитать заметку или получить их список нельзя: таких эндпоинтов пока нет.
- Авторизации нет: любой, кто видит сервер, может удалить любую заметку.
- Сервер рассчитан на один процесс: при нескольких воркерах у каждого свои заметки.
